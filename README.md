# 🌸 Iris Classifier Flow

### AI-Based Iris Flower Classification Web App
*Machine Learning (Scikit-learn + Flask) — Instant Flower Prediction*

---

## 🔍 What is Iris Classifier Flow?

**Iris Classifier Flow** is an AI-powered web application that predicts 
the type of Iris flower based on its measurements.

Simply enter the flower's measurements and the ML model instantly 
tells you which Iris type it is:

- 🌸 **Setosa**
- 🌺 **Versicolor**  
- 🌼 **Virginica**

---

## ✨ Main Features

- **Instant Prediction** : Enter measurements and get results in seconds
- **ML Powered** : Trained using Scikit-learn classification model
- **Simple UI** : Clean and easy-to-use web interface
- **Live Web App** : Deployed and accessible from any browser
